box A — auto-width prose (no explicit width; wraps against the containing block)

box A

This paragraph is box A. It has no explicit width, so it fills whatever containing block the layout viewport hands it, and its wrap points are the entire experiment: if CSS zoom truly divides the layout viewport rather than leaving it fixed at the iframe's real pixel width, this text re-wraps identically after root zoom flips from 1 to 2, even though the iframe element itself has grown to twice its size in real screen pixels. Watch the rendered line count in the report above rather than trusting your eyes — a doubled font size can look identical to a doubled viewport at a glance, and the whole point of this probe is to replace that glance with a number. If the line count changes when the zoom control flips, or if the ICB probe's offsetWidth moves instead of holding steady, the geometry assumption behind magnify mode is false and nothing past this file should be built.
