Every user-visible or wire-visible behavior of the Tauri app, with where it
lives, what the restored pre-#27 Swift shell did about it, and what a native
port owes. Swift `file:line` references are pinned to commit `08b8bec` (the
verbatim restore); the shell has moved since, so §12 items may already be done.
Row ids (L, B, C, T, D, H, P, K, S, W, Q, X) are stable and are what commits
and briefs cite.


Source of truth = the Tauri app on branch `feat/swift-native-ui`. `desktop/` and `core/` were read at `70a5983` and are byte-identical at `eddff58` (HEAD when this file was finished). Every `file:line` below was read directly.

## Conventions

- **Path shorthand.** `App.tsx`, `board/…`, `cards/…`, `ui/…`, `kit/…`, `theme/…`, `ipc/…`, `devDriver.ts` are under `desktop/src/`. Bare `*.rs` and `card_shim.js` are under `desktop/src-tauri/src/`. `proto/…` = `core/crates/tarmac-protocol/src/…`. Swift files without a prefix are under `app/Sources/TarmacApp/`; `Kit/…` = `app/Sources/TarmacKit/…`.
- **Swift status and Swift line numbers** describe `app/Sources/TarmacApp/` **as committed in `08b8bec`** (the verbatim pre-#27 shell; read it with `git show 08b8bec:app/Sources/TarmacApp/<file>`). The working tree was being edited concurrently while this was written (uncommitted deletion of `ShelfView.swift`, `DockPaneView.swift`, `PeekPanel.swift` and edits to nine other shell files), so line numbers in the live tree have shifted and some §12 items may already be done. `app/Sources/TarmacTerm/` lines are as of `eddff58`. `app/Sources/TarmacKit/` was *re-synced* with the TS kit afterwards (commits `bdc81ac`…`70a5983`), so a kit function can already be current while the shell that calls it is stale. PRESENT = the shell wires it today; "kit ready" in notes = pure logic exists in `Kit/` but the shell does not (correctly) use it.
- **Build fact.** `app/Package.swift:7-17` declares no `TarmacApp` target and no SwiftTerm dependency, so the old shell is not compiled today; `AppController.swift:2`, `RootView.swift:3`, `CardView.swift` still `import SwiftTerm`. `Makefile:46-55` (`native-run`) already expects a `TarmacApp` product and exports `TARMAC_DEV_LABEL`.
- **Spec ids** are files in `.blueprint/specs/` (historical records; the code line is authoritative).
- **Status vocabulary.** PRESENT `file:line` = the old shell already does this; PARTIAL = it does something related that differs (the difference is stated, including old behavior that must be *removed*); ABSENT = nothing there; n/a = the row is a web-only mechanism with no old-shell counterpart.
- Shelf, terminal dock pane, peek (⌘P) and locards are *not* gaps; they appear only in §12 as deletions.

## Open discrepancies found while reading (decide before porting)

1. **Dot grid** (B11): `architecture.md` describes a densifying dot grid; the Tauri code computes its metrics but no stylesheet paints it. Not verified on screen.
2. **Provenance edge shape** (P2): docs say bézier; code draws a straight segment.
3. **"Detached" cards** (C9): docs describe a detached mark on disconnect; code has none.
4. **⌘T / replacement focus** (T17, K5): as read, the new terminal becomes prime but nothing moves keyboard focus or selection to it.
5. **Reconnect history** (T5): with a surviving daemon, the per-connection scrollback replay is written into terminals that already hold that history.
6. **Terminal title precedence** (T10): the kit implements OSC > process > shell with revert; the app wires last-writer-wins.
7. **`active_element` in the QA snapshot** (Q11): DOM tag names are part of the `make qa` contract.
8. **Rename mode in ⌘K** (S10): navigation and ⌘N are not blocked while renaming.
9. **Keyboard while an HTML card is borrowed** (H11): the host key handler does not see keys typed into the document.
